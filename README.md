# 小deepseek

这是作者的处女作了，还有很多不好的地方希望各位能笑纳。

我是26年9月刚考上大学的，也是在暑假看了很多deepseek claude chatgpt grok等各种大模型的二创小短剧，也是喜欢上了可爱的拟人画风，所以就创作了蓝色大肥鱼的桌宠。

画一下饼：未来会添加换肤的功能，大家可以换上喜欢的小克、龙娘的皮肤，应该会很好看。

这个开源的桌宠是站在前人的肩膀上建立的，感谢：
